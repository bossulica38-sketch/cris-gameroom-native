# CRIS GameRoom

Jocuri și Discuții — client nativ Windows pentru platforma CRIS GameRoom.

## Platforme

- Windows 10
- Windows 11
- x64
- x86

## Funcționalități

- autentificare nativă
- camere GameRoom
- comunicare API
- comunicare realtime
- verificare versiune
- actualizare automată
- instalare și dezinstalare
- accesibilitate Windows

## Limbi

Română, engleză, portugheză, turcă, italiană, spaniolă, germană, franceză, neerlandeză și poloneză.
